# Audio Assets — /public/audio/

Place the following MP3 files here for the SFX system.
**If files are missing, playback will fail silently — the UI never blocks or crashes.**

| Filename                | Sound effect triggered on                | Triggered by          |
|-------------------------|------------------------------------------|-----------------------|
| cookie-confirmed.mp3    | Cookie preferences saved                 | Cookie banner confirm |
| document-download.mp3   | Download PDF button clicked              | Hero & section links  |
| official-stamp.mp3      | Submit Application button clicked        | Hero submit button    |

Files must be MP3 format, preferably < 2 seconds.
Volume is automatically set to 40% (0.4).
